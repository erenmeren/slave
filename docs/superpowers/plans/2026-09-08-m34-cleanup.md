# M34 Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the small, well-understood debts left by M25–M33 without changing any product behaviour a person would notice except where a wrong status code or a race was the bug: a not-found id is 404 on every route, a project department name is unique by index, the M33 drawer carries no runtime vocabulary, and the CLI's `claude` fallback is tested.

**Architecture:** One shared `refusalStatus(kind)` in `apps/web/src/server` feeds every route shell; one additive migration on `Team`; one field on `AdoptionPreview`; one exported pure helper in the orchestrator CLI. No new subsystems.

**Tech Stack:** TypeScript, Prisma 7 (migration), Next.js app router, vitest.

**Spec:** none — the design was approved in chat on 2026-09-08 (this file is the record). Binding references: M27 spec §3.3 (route shells), M33 spec §3–§4 (`AdoptionPreview`, drawer), M32 item 7 (`SLAVEOFAI_REQUIRE_FAKE_CLI`).

## Global Constraints
- No product behaviour changes beyond: `*_not_found` → 404 on the org/workspace/sim route shells; a duplicate department name in one project refuses `duplicate_name` under a race; the adopt drawer's minus sign is refused inline; nothing else a person can see.
- Every `*_not_found` refusal kind in `packages/control/src/refusal.ts` (today: `base_branch_not_found`, `company_not_found`, `company_slave_not_found`, `company_team_not_found`, `dependency_not_found`, `repo_not_found`, `run_not_found`, `simulation_not_found`, `skill_not_found`, `slave_not_found`, `task_not_found`, `team_not_found`, `template_not_found`, `user_not_found`, `workspace_not_found`) maps to 404; every other kind stays 409. The mapping lives in ONE place; no route file keeps its own set.
- The existing 404 pre-checks in `workspaceControlRoute.ts`, `controlRoute.ts`, `taskControlRoute.ts` stay (they answer before the verb runs and carry their own text).
- No sector name in control/web/CLI text or logic except through the registry (M31b/M33 rule).
- Vocabulary gate: the word is `slave` everywhere it is ours.
- One vitest at a time; `npm run --silent typecheck`; `npm run web:build` last for web tasks, never while `next dev` runs. Commit trailers as in M33: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Never a real model call; tests use `packages/providers/test/fake-claude.mjs`.
