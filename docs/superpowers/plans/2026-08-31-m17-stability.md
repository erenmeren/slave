# M17 Stability & Debt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the suite trustworthy (six named flakes root-caused), the providers runtime proven (direct tests where only inherited coverage exists), and the web queries bounded — no product feature.

**Architecture:** Four serial waves on `feature/m17-stability`: flake root-causing with a written ledger per flake; characterization tests for `packages/providers/src/runtime/`; SQL-side aggregation for three unbounded web queries behind equivalence tests; a small-works batch. A zero-spend `gate:m17-stability` closes the milestone: 5× consecutive full-suite green + a duplication census + equivalence-test presence.

**Tech Stack:** TypeScript monorepo (npm workspaces), Vitest 3.2.7 (root `vitest.config.ts`, `unit` + `integration` projects), Prisma + Postgres (shared test DB), Next.js (apps/web), playwright-core (gates), bash (gate scripts).

**Spec:** `docs/superpowers/specs/2026-08-31-m17-stability-design.md` (as amended 2026-08-31 by commit `69f94b4` — read the amended §3/§4/§5 before starting; the flake ledger it mandates is created in Task 1).

## Global Constraints

- Branch: `feature/m17-stability`, cut from `main`. Every task commits there.
- **One vitest run at a time, ever.** Concurrent runs TRUNCATE-collide on the shared test DB.
- **No orchestrator daemon may be running during any test run** — a live daemon changes the cluster-wide `LISTEN` count and breaks `subscribe.test.ts`. Check with `pgrep -f 'cli.js daemon'` before every suite run; kill what you find (your own dev daemons only).
- `npm test` = `tsc --build && vitest run`. Cross-package imports resolve to `dist/`, so after editing one package's source, run `npx tsc --build` before a targeted `npx vitest run` of another package's tests.
- Any task touching `apps/web` gates on `npm run web:build` before its commit. **Never** run `web:build` while a `next dev` server is up.
- Flake discipline (spec §2, binding): a retry that goes green is never evidence; a timeout is widened only with a measured margin calculation written into the ledger; every flake task ends with a ledger entry in `docs/superpowers/specs/2026-08-31-m17-flake-ledger.md` and a 20× green loop of the targeted test.
- Behaviour-preserving rule (spec §3/§7): existing tests are not edited to make a change fit, except where a task explicitly says which assertion changes and why.
- Commit messages follow the repo's style: a lower-case conventional prefix and a sentence that says what is true after the commit (see `git log --oneline -20` for the voice). Every commit ends with the Co-Authored-By/Claude-Session trailer used throughout this session.

```bash
#!/usr/bin/env bash
# scripts/repeat-test.sh — run one vitest file (optionally one test) N times, serially,
# stopping at the first failure. One tsc --build up front; the loop itself is pure vitest.
# The serial loop is deliberate: the shared test database allows ONE vitest run at a time.
set -euo pipefail

usage() { echo "usage: repeat-test.sh <N> <test-file> [test-name-pattern]" >&2; exit 2; }
[[ $# -ge 2 ]] || usage
N="$1"; FILE="$2"; NAME="${3-}"

if pgrep -f 'cli.js daemon' > /dev/null 2>&1; then
  echo "refusing to run: an orchestrator daemon is up (it skews the cluster-wide LISTEN count)" >&2
  exit 2
fi

npx tsc --build

for ((i = 1; i <= N; i++)); do
  echo "--- run ${i}/${N}: ${FILE}${NAME:+ -t \"${NAME}\"}"
  start=$(date +%s%3N)
  if [[ -n "${NAME}" ]]; then
    npx vitest run "${FILE}" -t "${NAME}" || { echo "RED on run ${i}/${N}" >&2; exit 1; }
  else
    npx vitest run "${FILE}" || { echo "RED on run ${i}/${N}" >&2; exit 1; }
  fi
  end=$(date +%s%3N)
  echo "--- run ${i}/${N}: GREEN in $((end - start)) ms"
done
echo "GREEN ${N}x"
```

```ts
let reconnectRequested = false

function scheduleReconnect(): void {
  if (closed) return
  // Never drop a disconnect: even while a loop is in flight, the request is recorded and the
  // loop re-checks it before it is allowed to end. This closes the window between
  // `current = client` and the old `reconnecting = false` where a second disconnect vanished.
  reconnectRequested = true
  if (reconnecting) return
  reconnecting = true
  reconnectPromise = (async () => {
    while (!closed && reconnectRequested) {
      reconnectRequested = false
      const stale = current
      current = null
      if (stale !== null) await endDiscardedClient(stale)
      try {
        await delay(RECONNECT_DELAY_MS)
        if (closed) break
        const client = await open()
        if (closed) {
          await endDiscardedClient(client)
          break
        }
        current = client
        // A disconnect that landed while open() was in flight set reconnectRequested again;
        // the while condition re-reads it before this loop may end.
      } catch {
        reconnectRequested = true // retry, preserving the old while(!closed) semantics
      }
    }
    reconnecting = false
    reconnectPromise = null
  })()
}
```

```ts
/**

 * Guards mirror the old in-memory loop exactly: a non-object column (Cursor's DbNull is SQL

export async function skillCallTotals(): Promise<ReadonlyMap<string, number>> {
```

```ts
interface AgentAggRow {
  readonly agentId: string
  readonly terminal: bigint
  readonly succeeded: bigint
  readonly durationMsSum: number | null
  readonly durationCount: bigint
  readonly reported: bigint
  readonly tokensSum: bigint | null
  readonly knownUsd: number | null
  readonly unmeasured: bigint
  readonly toolCalls: bigint
}

/** One row per agent that has ever run; every JS reduce from the old per-agent pass, as a FILTER. */
export async function perAgentRunAggregates(workspaceId: string | null): Promise<readonly AgentAggRow[]> {
  const scopeJoin = workspaceId === null
    ? Prisma.empty
    : Prisma.sql`JOIN "Agent" a ON a."id" = r."agentId" JOIN "Team" t ON t."id" = a."teamId" WHERE t."workspaceId" = ${workspaceId}`
  return prisma.$queryRaw<AgentAggRow[]>(Prisma.sql`
    SELECT r."agentId" AS "agentId",
      COUNT(*) FILTER (WHERE r."terminalAt" IS NOT NULL) AS terminal,
      COUNT(*) FILTER (WHERE r."terminalAt" IS NOT NULL AND r."status"::text = 'succeeded') AS succeeded,
      (SUM(EXTRACT(EPOCH FROM (r."endedAt" - r."startedAt")) * 1000)
        FILTER (WHERE r."terminalAt" IS NOT NULL AND r."endedAt" IS NOT NULL AND r."endedAt" >= r."startedAt"))::float8 AS "durationMsSum",
      COUNT(*) FILTER (WHERE r."terminalAt" IS NOT NULL AND r."endedAt" IS NOT NULL AND r."endedAt" >= r."startedAt") AS "durationCount",
      COUNT(*) FILTER (WHERE r."tokensIn" IS NOT NULL OR r."tokensOut" IS NOT NULL) AS reported,
      SUM(COALESCE(r."tokensIn", 0) + COALESCE(r."tokensOut", 0))
        FILTER (WHERE r."tokensIn" IS NOT NULL OR r."tokensOut" IS NOT NULL) AS "tokensSum",
      SUM(r."costUsd")::float8 AS "knownUsd",
      COUNT(*) FILTER (WHERE r."costUsd" IS NULL AND r."provider" IS NOT NULL
        AND r."status"::text NOT IN (${Prisma.join([...NON_TERMINAL_RUN_STATUSES])})) AS unmeasured,
      SUM(r."toolCalls") AS "toolCalls"
    FROM "AgentRun" r
    ${scopeJoin}
    GROUP BY r."agentId"`)
```

```ts
export function runFilePaths(repoPath: string, runId: RunId): { runDir: string; pauseFlagPath: string } {

  let root
```
