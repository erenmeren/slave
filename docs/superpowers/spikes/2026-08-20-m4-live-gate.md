## Finding the gate caught (fixed on the branch)

**The action line showed `toolu_…` ids against the real CLI.** The fake's fixtures made this
invisible in CI: M3's pump emitted `summary: toolUseId`, with a comment assigning the richer
summary to M4 — which the M4 plan missed. Fixed in `f008402`: the providers parser now derives a
readable summary from the `tool_use` block's `input` (tool name + primary argument, whitespace
collapsed, 80-char cap), the pump emits it, and run 3 above is the live proof. The moral matches
M3's gate: the shapes only the real CLI produces are exactly the ones the gate exists to see.
