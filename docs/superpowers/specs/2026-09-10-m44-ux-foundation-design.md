# M44 — UX foundation A: information architecture, navigation, design system, status language

First milestone of the roadmap `2026-09-10-roadmap-m44-m56.md`. Designed 2026-09-10 from an inventory of every route, panel, control, token and test in `apps/web` (kept in the session scratchpad; its conclusions are in `docs/ia.md`, a deliverable of this milestone). Every **Ruling** took the recommended option; the user can rework any of them before or during execution. "Slave" is this project's word for an AI worker.

**Goal.** Simplify the existing application before more visible complexity arrives: one navigation a normal user can predict, one page shell and one set of primitives every page uses, one user-facing status vocabulary projected from backend state, and the accessibility/responsive basics — without removing any capability (everything that leaves the main paths stays reachable under "Advanced"). No feature work; M45 builds the Supervisor-centred project view on this foundation.

**What the inventory found (the audit's headline).** 10 global pages + 6 project pages; a 6-row sidebar (Projects, Slaves, Simulations, Skills, Analytics, Settings) and 6 project tabs (Overview, Tasks, Graph, Office, Activity, Settings); four surfaces for "a slave" (templates, company roster, the merged `/slaves` table, project cards); three live views over one event stream; two button systems, three card DOM shapes, two grid-table idioms, ad-hoc hex colours and radius literals; raw enum values rendered on six surfaces (`pausing`, `situationKind · tier · status`, event-type prefixes…); ~9 hand-rolled Escape handlers, no focus trap, no skip link, responsive variants in 6 of ~90 files; `gate:m14-fidelity` screenshots nine pages at 1440×900 and asserts README pixel values.

## 1. Rulings

- **R1 — Top-level navigation: four entries.** `Projects` (home: the project list with health), `Workforce` (the people: project slaves, departments, companies, templates/catalog, skills — as tabs inside one page), `Simulations`, `Settings`. `Analytics` leaves the sidebar: its all-workspaces view becomes a section on the Projects home; its per-workspace view is reached from the project (Activity tab's "Analytics" link) — the `/analytics` route stays (fidelity gate, bookmarks). `Skills` and `Slaves` leave the sidebar as pages and become Workforce tabs. Why: the prompt's mental model, the inventory's four-surfaces-for-one-concept finding; cost if wrong: two labels to rename.
- **R2 — Project tabs: Overview, Tasks, Activity, Settings, plus an `Advanced` menu (Graph, Office).** Graph's five modes and the pixel office remain complete and reachable from the menu and by URL; they leave the tab strip because a normal user does not need them to answer "what is happening". M45 adds `Organization` (the org graph mode's content in a plain view) and rewrites Overview around the Supervisor; M44 does not touch panel content. Why: fewer tabs, no capability removed; cost if wrong: a menu item back into a tab.
- **R3 — One shared shell and one primitive set, extending `components/ui`.** `PageShell` (max width, gutters, title row, optional tabs slot), one `Button` (variants `primary | ghost | danger`, sizes `md | sm`; `FormControls`' `GhostButton`/`PrimaryButton` become aliases then are removed from call sites), `Card` accepting `className`/data attributes so `SlaveCard`/`TaskCard`/`ProjectCard` share one surface recipe, `Tabs` (segmented, `role="tablist"`, URL- or state-backed) used by Workforce, Graph modes, Simulation tabs and the project strip, `Dialog` and `Drawer` primitives that own Escape, focus trap, focus restore and `aria-modal`, `Alert` (`error | notice | success`) replacing ad-hoc `role="alert"` bands, `EmptyState`, `LoadingState`, `DangerConfirm` as the ONLY destructive recipe (EmergencyStop and DangerZone adopt it), tokens for every ad-hoc colour and one spelling per radius. Pixel values the README documents (sidebar 212, header 52, card radius 8, pill 20, live panel 340…) stay unchanged in this milestone so `gate:m14-fidelity` keeps its assertions; the sidebar collapses to icons below 900 px. Office's canvas is untouched (Advanced). Why: the smallest consolidation that makes M45's new panels cheap; cost if wrong: primitives are additive.
- **R4 — Status language is a pure domain projection.** `packages/domain/src/status/user.ts`: `userTaskStatus(task) → { state, label, needsYou }` with states `queued | working | verifying | review | merging | waiting | blocked | done | integrated | failed | cancelled` and labels QUEUED / WORKING / VERIFYING / IN REVIEW / MERGING / WAITING / BLOCKED / DONE / INTEGRATED / FAILED / CANCELLED; `needsYou` is true for `blocked`, for `waiting` when the pending question has no slave holder (M39's unanswerable case) or a decision is pending human approval, and for `done` with `integratedAt: null` on a hand-merge workspace ("ready to integrate"). `userRunStatus` and `userSlaveStatus` fold the existing `CardState` mapping (`apps/web/src/lib/tones.ts`) into the domain and the web imports it; `userWorkspaceStatus` gives the project row one word (HALTED / WAITING FOR YOU / WORKING / IDLE / ARCHIVED). Raw values remain available in every expanded view and in `title` attributes. Why: one vocabulary, testable without React; cost if wrong: a label table.
- **R5 — Six raw-value leaks are closed, nothing else is re-written.** The Slaves table and `SlavePanel` header, Activity's event-type rail (prefix → a short label table with the raw type in `title`), Skills' `ready/missing` state, the Supervisor decision rows (situation kind → the M38 situation label, tier/status → words), simulation status chips (`ready/running/paused/finished/halted` → words). Panel logic is unchanged.
- **R6 — Accessibility and responsiveness basics:** a skip link to `main`, `Dialog`/`Drawer` focus management (R3), `role="tab"` on the Graph mode nav via `Tabs`, the sidebar collapse, page-level `md:` breakpoints for the shell and the Workforce/Projects grids; the Office canvas gets an `aria-label` and a text fallback line, nothing more.
- **R7 — `docs/ia.md` is a deliverable and a contract.** One table per surface: route → user goal → decision (keep / merge into / demote to Advanced / unchanged) → what M44 does → what a later milestone does. Concise; it is what M45–M56 read before adding a surface. "Do not build a dashboard for everything" is a rule in it.
- **R8 — The gate.** `gate:m44-ux-foundation` (Playwright, fake CLI, like m14): the four sidebar entries and their targets; the project tab strip + Advanced menu; every page renders inside `PageShell`; no raw enum token (`pause_requested`, `waiting_for_answer`, `situationKind` strings, `run_tool_call`…) is visible text on the nine fidelity pages plus `/w/:id/settings` and `/w/:id/office`; a drawer traps Tab and restores focus on Escape; the skip link is the first focusable element; the sidebar is collapsed at 800 px; simulated money and model cost never share a tile (a DOM scan for `$` tiles inside `data-simulation` vs real containers). `gate:m14-fidelity` is re-run and its nine PNGs regenerated in a deliberate commit (Office and project Settings added to its page set, with their `data-testid`s).
- **Never a real model call; one vitest at a time; `web:build` last and never beside `next dev`; vocabulary `slave`; no migration; no functionality removed — anything leaving a main path is listed in `docs/ia.md` with its Advanced location.**

## 2. Surfaces after M44
- `Sidebar`: Projects · Workforce · Simulations · Settings (icons + labels; collapsed variant).
- `/` Projects home: project cards with `userWorkspaceStatus`, "needs you" count, a compact all-workspaces analytics section (the existing KPI tiles), the New project action. The template catalog + companies section MOVES to Workforce → Catalog.
- `/workforce` (new route; `/slaves` and `/skills` redirect to its tabs): tabs `Slaves` (the merged table, statuses projected), `Departments`, `Catalog` (companies, templates, catalog imports — the M42 panels), `Skills` (the skills page content).
- `/w/:id` tabs: Overview · Tasks · Activity · Settings; `Advanced ▾`: Graph, Office. Header unchanged.
- Primitives in `components/ui`: `PageShell`, `Button`, `Card`, `Tabs`, `Dialog`, `Drawer`, `Alert`, `EmptyState`, `LoadingState`, `DangerConfirm`, existing `Panel`/`Chip`/`StatusPill`/`DataTable`/`StatStrip`/`ProgressBar`/`AvatarTile` kept.
- `packages/domain/src/status/user.ts` + tests; `apps/web/src/lib/tones.ts` re-exports from the domain.

## 3. Out of scope (M45+)
Overview content, the Supervisor conversation surface, an Organization tab, progressive-disclosure task/worker panels (M45); profile/catalog UI (M46); any change to control routes or read models beyond what the projection needs; new charts; animations.
